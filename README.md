### Print
Možna uporaba funckije print. Print na konec sam doda novo vrstico.

```python
print("Hello world!")
# Hello world!

print("Hej,", "to", "je", "print")
#Hej, to je print

pozdrav = "Živjo"
print(pozdrav)
#Živjo
```

####<em>Ne želiš nove vrstice?</em>
```python
print("Živjo", end=" ")
print("ti")
#Živjo ti
```

Parameter <b>end</b> določi ločilo med elementi printa.
